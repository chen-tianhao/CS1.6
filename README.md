# CS 1.6 · WEB EDITION

浏览器里跑的 Counter-Strike 1.6 风格单机战术射击：**规则、数值、移动物理按 CS 1.6 / GoldSrc 复刻**，
**地图、贴图、音效、武器模型全部原创或程序化生成**（不含任何 Valve 素材）。

打开 `index.html` 即可运行（无需服务器、无需联网）。

---

## 一、能复刻到什么程度

| 项目 | 状态 | 说明 |
| --- | --- | --- |
| 移动物理 | ✅ 高保真 | 按 GoldSrc `PM_Accelerate` / `PM_AirAccelerate` 实现：250 跑速、268 起跳、空中加速上限 30（可连跳 / 空中转向）、地面摩擦 4、蹲速 0.34、静步 0.52、18 单位台阶 |
| 武器数值 | ✅ 高保真 | AK-47 / M4A1 / AWP / Scout / SG552 / AUG / MP5 / P90 / Deagle / USP / Glock / 刀 / 三种投掷物；伤害、射速、弹匣、护甲穿透、按距离衰减、4 倍爆头 |
| 后坐力 | ✅ 近似 | 视角 punch 上抬 + 水平摆动，AK 前 4 发近竖直、10 发后左右摆；松开自动回正，需手动压枪 |
| 经济系统 | ✅ 高保真 | $800 起步、上限 $16000、胜方 3250 / 拆包胜 3500、连败 1400→3400、安包 +800、各枪击杀奖励（刀 1500、AWP 100、其余 300） |
| 回合流程 | ✅ 高保真 | 3s 冻结 → 115s 回合 → 4.5s 结算；C4 35s、安放 3.2s、拆包 10s / 带包 5s；MR15，先到 16 分，第 15 回合后换边 |
| BOT | ✅ 可用 | A* 栅格寻路、视野锥 + 射线 + 烟雾遮挡判定、反应时间/瞄准误差按难度分级、站定对枪与换位、集火报点、捡包、安包、拆包 |
| HUD | ✅ 复刻风格 | 血量/护甲/弹药/资金、雷达（队友常显、敌人需被看见）、击杀提示、计分板、购买菜单、开局与回合播报 |
| 地图 | ⚠️ 原创 | `de_outpost` 沙漠双点图（A/B 点、Long、Mid 折线、B 通道、CT 坡道），复刻的是 **dust2 的战术结构**，不是原始几何 |
| 联机 | ❌ 未实现 | 只有单机 + BOT；联机需要独立服务端与 netcode |
| 原版资产 | ❌ 不可能 | BSP / mdl / wad / 原版音效均为版权资产，且 GoldSrc 引擎闭源 |

> 结论：**"规则与手感层面"高度还原，"资产与引擎层面"另起炉灶。** 这也是网页端复刻经典 FPS 的现实边界。

## 二、操作

| 键 | 功能 | 键 | 功能 |
| --- | --- | --- | --- |
| WASD | 移动 | 空格 | 跳跃（需重新按下，不自动连跳） |
| Shift | 静步 | Ctrl / C | 下蹲 |
| 左键 | 射击 / 投掷 | 右键 | 开镜（AWP / Scout / SG552 / AUG） |
| R | 换弹 | 1 / 2 / 3 / 4 | 主武器 / 手枪 / 刀 / 手雷（循环切换） |
| Q | 快速切枪 | B | 购买菜单（需在出生区） |
| E | 安放 / 拆除 C4（按住） | TAB | 计分板 |
| ESC | 暂停（释放鼠标） | 滚轮 | 循环切枪 |

死亡后左键切换观察视角；比赛结束按 R 重开。

## 三、运行

**方式一：直接打开**
双击 `index.html`。所有资源都是本地文件，无需服务器。

**方式二：本地服务器（推荐，避免个别浏览器的 file:// 限制）**

```bash
cd web-cs16
python -m http.server 8123
# 浏览器访问 http://localhost:8123
```

点击"进入战场"后浏览器会请求鼠标锁定；若环境不允许（例如被嵌在 iframe 里），
会自动降级为**按住左键拖动转视角**，功能不受影响。

## 四、目录结构

```
web-cs16/
├── index.html          # 页面骨架 + HUD DOM
├── assets/game.js      # 打包产物（esbuild 输出，直接可跑）
├── src/
│   ├── config.js       # 武器/经济/物理/回合常量 —— 想改数值先看这里
│   ├── map.js          # 区域矩形 → 栅格 → 自动封墙；碰撞体、A* 导航、雷达底图
│   ├── player.js       # GoldSrc 运动、命中盒、武器持有、角色模型
│   ├── weapons.js      # 弹道、伤害结算、护甲/爆头倍率
│   ├── bots.js         # BOT 感知 / 决策 / 交战 / 目标行为
│   ├── round.js        # 回合状态机、经济、C4、购买逻辑
│   ├── fx.js           # 枪口焰、曳光、弹孔、爆炸、烟雾、投掷物物理
│   ├── viewmodel.js    # 第一人称武器（独立渲染层，避免插墙）
│   ├── hud.js          # HUD / 雷达 / 购买菜单 / 计分板
│   ├── audio.js        # WebAudio 程序化枪声与音效
│   ├── textures.js     # Canvas 程序化贴图（沙岩、木箱、混凝土、金属、天空）
│   └── style.css       # CS 风格界面样式
└── test/               # 无头 Chrome 自动化验证脚本（冒烟/战斗/回合/截图）
```

重新构建（改了 `src/` 之后）：

```bash
npm install
npm run build     # 输出 assets/game.js
```

## 五、调参入口

`src/config.js`：

- `PHYS`：重力、跑速、加速度、空中加速上限、跳跃初速、台阶高度
- `RULES`：冻结/回合/C4/拆包时长、经济数值、MR 局数与换边点
- `WEAPONS`：每把枪的伤害、射速、弹匣、散布、后坐、移动速度、击杀奖励
- `SETTINGS_DEFAULT`：灵敏度、FOV、音量、准星颜色/大小/间隙

地图在 `src/map.js` 的 `AREAS` 数组里，用矩形描述房间与通道，墙体、碰撞、导航会自动生成。

## 六、已知限制

1. BOT 只有"够用"级别的战术：会集火、会守点、会安包拆包，但没有投掷物配合与假动作。
2. 地图是原创布局，不是 `de_dust2` 的一比一还原；只有战术节奏相似。
3. 无联机、无录像、无 Steam 成就式的统计持久化。
4. 画面是低模方块风格；没有骨骼动画、没有布娃娃物理。
5. 音效为 WebAudio 合成，不是原版采样。
